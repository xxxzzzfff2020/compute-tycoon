# H5 经济模拟审计｜合同协调后｜2026-08-01

## 结论

8 个冻结策略各 1000 局，共 8000 局，第一次迭代失败率均为 0%。标准策略全部进入新目标区间；不训练并非全面最优，合理训练不是陷阱，模型优先没有拖慢八服，混合离线真实使用与正式 Session 相同的资金/研发/旗舰离线规则和存储上限。6 个模型在所有策略中获取率均为 100%，且都有正向运行贡献。

## 方法与计时修正

`scripts/simulate-economy.ts` 以 1 秒步长直接调用正式订单、训练、免费研发、服务器、蓝图、基础设施、机房、旗舰、离线和第一次迭代引擎。每个策略是确定性的，因此同策略的 p10/p50/p90 相同；1000 局用于证明重复执行稳定和失败率，不代表随机置信区间。

本轮修正了旧模拟的时钟口径：投产红利现在按生产时钟仅持续 25 秒，不再因 `now=0` 被错误当成永久 ×4。以下结果均为修正后真值。

## 策略平衡判断

- `no_training` 的八服、机房和迭代均慢于合理训练，不是全面最优。
- `reasonable_training` 与 `automation` 在标准之后更快完成后半程，训练不是死亡陷阱。
- `model_first` 八服 26:14，未因研发/训练显著拖慢八服。
- `income_first` 首服最快，但首单约 2:59、自动经营约 6:01，牺牲了开场反馈，不是无代价优势。
- `server_first` 八服和后半程最慢之一，证明盲目囤钱并非唯一正确策略。
- 存储没有进入直接收入、吞吐、总算力或旗舰速度；它不是即时收入的唯一强制最优升级。
