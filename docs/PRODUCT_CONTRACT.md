## 一、唯一产品目标

验证一条完整核心循环（标准首轮 80–100 分钟在线等效，可跨多次回来）：

1. **Stage1 · AI 创业工作室**：获得第一款 AI 模型 → 接第一批订单 → 使用租赁算力处理 → 获得收入 → 训练/研发更强模型 → 解锁自动经营 → 工作室等级与累计收入达标 → 里程碑取得第一台自有服务器（不扣当前资金）。
2. **Stage2 · 服务器集群**：1 台自有算力 → 3/5/8 台按规模自动永久解锁三项架构节点（全局倍率约 ×1.45/×2.10/×3.05）→ 8 台完整服务器集群；自动经营按业务组合运转；模型持续研发；订单表现按吞吐切三档（单笔/业务流水/算力结算）→ Stage 2 结算 → 解锁算力中心。
3. **Stage3 · 算力中心**：8 台折叠为集群核心机房 → 四项全局基础设施（电力/算力卡/光模块/存储）→ 瓶颈识别 → 机房 2 / 机房 3 投产（数量级爽感）→ 三项旗舰算力工程 → 算力档案馆（模型图鉴/集群架构/科技档案/算力纪元）。
4. **地球三轮技术迭代**：R1/R2 完成时代工程并手动领取核心后重建地球进度；永久倍率依次为 ×1.5、×2.0。R3 领取核心 3 后执行第三次迭代，保持地球进度并揭示地外算力计划，永久倍率保持 ×2.0。
5. **终局闭环**：手动启动 Stage4 地月算力网 → 完成地月一体化算力网 → 进入 Stage5 戴森算力纪元 → 完成戴森算力球 → 生成传奇档案并进入永续增长；不存在第四次迭代。

Release Candidate 已包含 15 项轻量里程碑与两处自愿激励广告合同；云存档和排行榜因 H5 真容器身份/服务端权威链尚未闭合而关闭 feature flag。`?adtest=1` 仍只属于隔离联调探针。

2026-08-08 人工最新范围裁决：**云存档、轻量成就、轻量排行榜属于后续计划，不再作为永久 CUT**；其中排行榜必须等待云端权威校验/防篡改前置成立后再开放。仍明确不做：随机事件系统、戴森后的无限解锁、签到、新货币、第四次迭代、复杂模型/逐服务器配置、Lua 工程修改。永续增长不再改变世界尺度。

## 二、阶段定义

- **Stage 1 完成**：获得模型 → 完成订单 → 解锁自动经营 → 工作室等级 ≥6 且累计收入 ≥¥24,000 → 取得第一台服务器 → 第一台服务器开始产生收入。
- **Stage 2 完成**：8 台服务器 + 集群里程碑 → Stage 2 结算（exactly-once）→ 解锁 Stage 3 入口。8 台前不显示 Stage 3 标签。
- **Stage 3 进入**：8 台 + Stage 2 结算完成 → 8 台折叠为"集群核心机房"（机房 1，不重复购买）→ 主页面从订单/服务器切换为算力中心与机房。
- **每轮地球迭代**：机房 3 投产 + 三项旗舰工程完成 → 完成本轮唯一时代工程（R1/R2/R3）→ 手动领取对应奇点核心 → 执行迭代。当前轮运行中的时代工程不可重复启动或被旧轮工程替换。
- **Stage4/5**：第三次迭代揭示地外计划；玩家手动进入 Stage4。地月主线领取完成后必须出现 Stage5 入口；戴森算力球领取后进入永续结局。

## 四、订单表现三档

| 模式 | 适用 | 展示 |

## 五、界面契约

- 单页分阶段区域（模型研发 / 订单 / 租赁与服务器 / Stage 3 筹建 / 技术迭代 / 算力中心与机房 / 算力档案馆），未解锁区域折叠；旧中心升级区永久隐藏，Stage 3 隐藏订单/服务器细节。
- 顶部始终可见：当前资金、收入/秒、总算力、工作室等级、累计营业收入、服务器数量 X/8（Stage 3 为机房数量与旗舰工程状态）、模型倍率、模型研发进度。顶部资金 `<=1e12` 保留完整千分位，超过后按兆→京→科学计数法；其他规模数值按万→亿→兆→京→科学计数法。
- 主要按钮：接取订单、训练当前模型、研发新模型、购买下一台服务器、开启自动经营、进入 Stage 3、升级基础设施/瓶颈、建设并投产机房、启动/领取旗舰工程、进行技术迭代。不存在旧中心升级按钮或蓝图三选一按钮。
- 购买服务器显示"购买后 服务器 X→X+1 · 总算力 A→B · 预计收入/秒 C→D"；升级基础设施显示"Lv → Lv+1 · 总算力 A→B · 预计收入/秒 C→D"。
- 机房投产同时发生：机房数量增加、总算力/收入跳升（≥3x）、规模名称变化、解锁新旗舰工程、启动 60 秒 ×4 红利。
- 关键成长必须即时反馈；禁止每个收入 tick 播放声音、大量连续弹窗、长动画阻断操作。

## 七、渲染与运行时合同

- 静态 DOM 初始化一次；稳定节点引用；`textContent`/`style`/`disabled` 局部更新；不替换应用根节点。
- 页面结构仅在结构性事件重建：首次获得模型、解锁自动经营、获得首服、阶段切换、技术迭代、进入 Stage 3、机房投产、旗舰工程状态变化。
- 普通订单完成、收入 tick、旗舰工程进度 tick 属于局部 patch；自动保存不触发额外完整渲染。
- 保持滚动位置与按钮焦点；不闪白、不清空容器、不重新挂载整个应用；不引入 React/Vue 等大型框架。
- 运行指标：`full_render_count` / `partial_patch_count` / `root_replacement_count` / `order_completion_count` / DOM 节点数（10 分钟运行稳定）。

## 八、技术迭代与终局合同

R1/R2 重置：当前资金、订单、租赁算力、服务器数量、机房、基础设施等级、工作室等级与经验、本轮模型训练、旗舰工程状态、Stage 2 结算标记。
永久保留：已获得模型与图鉴等级、固定架构节点、科技/时代档案、已领取奇点核心、技术迭代次数、永久收入倍率、历史最高收入/算力、累计营业收入、设置、存档身份。
倍率：`[1.5, 2.0, 2.0]`；不是等比翻倍。R3 不执行普通清档，只揭示地外算力计划。
历史迁移：旧档 `technologyIterationCount=1/2/3` 且 `singularity` 缺失时，仅回填对应 `core_1/core_2/core_3` 历史完成事实；不得补发资金、倍率、模型、庆典或再次清档。应用启动、文件导入和游戏内完整重置必须进入同一当前终局合同；导入迁移在校验与单次写盘前完成，失败不得覆盖现档。迁移幂等。
时代工程：只允许当前轮工程；活动中或存在待领奖励时禁止再次启动，避免进度清零。
终局：Stage4 奖励领取后显示 Stage5 入口；Stage5 戴森球领取后生成一次传奇档案并进入永续增长，禁止任何后续迭代。

## 九、离线合同

- 主时间口径：三轮总在线等效 6-10 小时；日历跨度 3-7 天；有效操作 2-4 小时。
- Stage 2 离线：效率 60%、上限 60 分钟。Stage 3：效率 70%、基础上限 60 分钟；存储 Lv1–8 每级 +15 分钟，最高 180 分钟。资金与研发使用同一时间上限。
- 存储每高于当前旗舰工程最低要求 1 级，最终资金奖励 +5%，单工程上限 +25%；完成时快照。存储不进入速度、吞吐、算力或直接收入公式。
- 离线只产生：资金、模型研发进度、旗舰工程普通处理进度。
- 离线不得自动执行：模型抽取/切换、服务器购买、基础设施升级、机房投产、旗舰工程领奖、阶段结算、技术迭代。
- 离线收益 exactly-once；不与在线收益重叠；日期回拨安全；刷新不重复领取；离线回来后 60 秒内至少一个清晰可执行动作。
