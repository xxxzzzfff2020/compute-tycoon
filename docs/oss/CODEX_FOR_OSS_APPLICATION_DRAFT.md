## Longer Project Statement

Compute Tycoon is a newly public, MIT-licensed TypeScript project that is both a playable incremental game and a reproducible reference implementation for human-governed, agent-assisted software development.

The repository publishes its product contracts, agent roles, versioned save and migration rules, 383 unit tests, end-to-end testing, 8,000-run economy simulations, bilingual i18n, and evidence-driven browser and release QA. Codex has been used for repository audits, bug diagnosis, regression testing, migration verification, browser QA, and release hardening.

We are applying for Codex for Open Source to turn these practices into reusable maintainer automation for pull-request review, issue triage, release evidence, and security checks. The resulting workflows, templates, and evaluation evidence will remain public for other TypeScript game and web application maintainers to reuse.
