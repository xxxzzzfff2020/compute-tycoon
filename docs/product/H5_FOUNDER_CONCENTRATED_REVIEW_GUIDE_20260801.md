## 怎么体验

登录私密站点后，优先选择“从新档完整开始”，自然走完 Stage 1–3、第一次技术迭代与第二轮首服。若需要复看某个关键时刻，再返回评审首页使用 A–J 检查点。每个检查点使用独立、合法、可刷新恢复的真实存档；重置当前检查点不会碰正式产品存档，也不会影响其他检查点。会话栏可将整体游戏时间切换为 1/2/4/8/16/32×，切换后刷新并继续同一检查点存档；评价正式节奏时请使用 1×。

集中体验只需判断五件事：

1. 核心增长循环是否有趣，数字增长是否持续清晰？
2. Stage 1 工作室、Stage 2 集群、Stage 3 算力中心的尺度变化是否成立？
3. 机房投产与第一次技术迭代是否形成足够的奖励感？
4. 六模型、架构蓝图与档案馆是否提供长期动力，而没有重新变成复杂配置？
5. 是否批准另开合同批讨论第二、第三次迭代和无尽纪元？

### 本轮低成本美术候选

本候选只调整表现层，不改变玩法、经济、存档或页面数量。体验时请同时观察：Stage 1/2/3 的暖橙工作室、青蓝服务器集群、青紫算力中心是否形成明确阶段身份；八格服务器阵列和三座机房是否让规模增长可见；旗舰工程、档案馆收藏卡与技术迭代面板是否比旧文字清单更容易理解并更有奖励感。所有反馈均由 CSS 与现有 DOM 完成，没有新增图片、视频、音乐或音效。

## A–J 检查点

- A 新档开始：完整自然流程和核心循环理解。
- B 自动经营刚解锁：手动订单是否自然让位于自动吞吐。
- C 第一台服务器即将获得：里程碑授予是否清晰，获得后是否立即变强。
- D 3 台服务器与架构选择：规模变化和少量长期选择是否有价值。
- E 8 台服务器与高吞吐：高频业务是否稳定聚合，Stage 3 是否没有提前出现。
- F Stage 3 刚进入：服务器集群折入机房后，尺度跃迁和四类基础设施职责是否清楚。
- G 机房 2 即将投产：投产、倍率跳升和 25 秒红利是否够爽。
- H 机房 3 与最终旗舰工程：Stage 3 收官是否形成高潮。
- I 第一次技术迭代确认页：重置/保留内容是否可理解，是否像奖励而不是清档。
- J 第二轮与首服加速：永久倍率、提前自动化和恢复速度是否明显。
