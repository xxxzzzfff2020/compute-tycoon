## 1. 六模型冻结

首发模型恰好 6 个，全部从同一免费研发池获得。一个模型为当前主力；所有已拥有模型在档案馆提供小额永久被动；重复研发只提升命中的模型图鉴等级。

| 模型 | 唯一职责 | 主力效果 | 图鉴被动 |
|---|---|---:|---:|
| 代码推理模型 | 基础业务收益 | +10% | 每级 +1%，上限 +5% |
| 视觉生成模型 | 处理速度 | +12% | 每级 +1%，上限 +5% |
| 语音合成模型 | 高价值业务占比 | 高价值权重 +100% | 每级 +5%，上限 +25% |
| 科学计算模型 | 自动经营效率 | +12% | 每级 +1%，上限 +5% |
| 知识蒸馏模型 | 模型研发速度 | +15% | 每级 +1%，上限 +5% |
| 工程调度模型 | 旗舰工程效率 | +15% | 每级 +1%，上限 +5% |

7–8 号模型后置；本候选没有新增模型配置、货币、配队、词条或逐服务器部署。

## 2. Stage 3 唯一路径与旧档协调

正式路径只有：

`8 台服务器 → Stage 2 结算 → 算力中心筹建 → Stage 3`

`computeCenterLevel` 不再出现在可点击 UI、主操作、收入、算力或 Stage 3 资格公式中。字段只用于读取旧存档，并在 schema v3 规范化为 0。

- 只有旧网关标记、服务器少于 8 且无真实 Stage 3 数据：回到 Stage 2；不解锁、不退款、不补奖。
- 存在基础设施、机房 2/3、旗舰工程，或“旧网关标记 + 技术迭代记录”：保留真实进度，补齐 8 服、Stage 2 结算、Stage 3 和机房 1 不变量。
- schema v3 写回后重复加载不再迁移，奖励不重复。

## 3. 存储与光模块

存储只负责：

- 当前旗舰工程最低要求以上，每级最终资金奖励 +5%，单工程上限 +25%；完成时快照倍率，延迟领取不改变奖励。
- Stage 3 离线资金与离线模型研发共用一个时间上限：基础 60 分钟，存储 Lv1–8 每级 +15 分钟，最高 180 分钟。

存储不改变旗舰速度、有效吞吐、总算力或直接收入。光模块继续改变有效吞吐、收入转化和旗舰速度。UI 同时显示存储升级前后的离线上限及旗舰资金奖励倍率，不承诺“工程速度提高”。

## 4. 曲线协调

修正后的生产时钟揭示旧模拟曾把 25 秒投产红利当成永久效果。本轮未整体降价、未整体提高收入、未删除机房或旗舰。唯一后半程校准是：机房 3 使用电力/算力卡/光模块/存储 `6/7/5/5` 的中段门槛；最终旗舰仍要求存储 8，保留后续成长段；机房 1 首次投产获得与机房 2/3 相同的一次性 25 秒 ×4 红利。

标准轨迹结果：首服 8:02、8 服 28:50、机房 2 49:28、机房 3 约 71 分、第一次迭代约 81 分、二轮首服 1:13（约为首轮 15%）。全部进入冻结区间。
