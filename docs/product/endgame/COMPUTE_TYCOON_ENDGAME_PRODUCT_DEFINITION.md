## 1. 核心问题与新长期爽点

**旧问题**：只有“数字变大”，缺少“世界尺度发生变化”；旧无限迭代倍率 ×2、×4、×8、×16、×32 会让周目从数小时缩到几十分钟，失去目标感。

**新定义**：玩家不只是让数字变大，而是让自己的算力事业从 AI 工作室 → 服务器集群 → 地球算力中心 → 地月网络 → 恒星计算 → 银河级算力文明，逐步突破尺度。

主线结构（最终态）：

```text
地球主线（3 次技术迭代，有限）
  R1 建成资产 → R2 连接网络 → R3 治理全域
  ↓ 第 3 枚奇点核心 + 地外算力计划揭示（玩家确认后进入，不自动）
Stage 4 地月算力网（新尺度，重新减速）
  ↓ 完成地月一体化算力网
Stage 5 戴森算力纪元（最终终局）
  ↓ 完成戴森算力球
永续增长模式（可继续购买/升级/观察数字永久增长；主线完成反馈；身份固定“银河算力大亨”）
```

## 2. 地球主线：有限三次迭代（加法式永久倍率）

### 2.1 全文档唯一时序（强制）

```text
R1 时代工程完成 → 手动领取核心 1 → 执行第一次技术迭代 → 进入 R2
R2 时代工程完成 → 手动领取核心 2 → 执行第二次技术迭代 → 进入 R3
R3 时代工程完成 → 手动领取核心 3 → 第三次技术迭代转化为“地外算力计划”揭示（不再执行普通地球清档）→ 玩家确认后进入 Stage 4
```

- 每轮仅一枚、仅一次；奇点核心必须手动领取（不自动领取、不挂机领取）。
- 顶部长期显示当前动态值 **“奇点核心 n/3”**（n=已获得枚数，0/1/2/3），不得显示“0/3/1/3/2/3/3/3”之类的全序列。

### 2.2 永久倍率表

| 节点 | 累计永久总倍率 | 增量 | 说明 |
|---|---|---|---|
| 初始 | ×1.00 | — | 当前 v8 基线 |
| 第 1 次迭代（核心 1） | ×1.50 | +0.50 | R1 完成后 |
| 第 2 次迭代（核心 2） | ×2.00 | +0.50 | R2 完成后；加法式，不几何翻倍 |
| 第 3 次迭代（核心 3） | ×2.50 | +0.50 | R3 完成后；此后地球迭代倍率不再增加 |
| Stage 4 / Stage 5 | ×2.50 保持不变 | — | 宇宙阶段靠自身减速与尺度曲线，不被永久倍率跳过 |

- 首选模拟表 A：×1.5 / ×2.0 / ×2.5；备用表 B：×1.35 / ×1.70 / ×2.00（仅当 A 触发压缩 >40% 时自动回退，无需再次询问）。

### 2.3 每轮差异（避免重复疲劳）

| 轮次 | 唯一经营问题 | 主要感受 | 新增内容（低资产成本） |
|---|---|---|---|
| R1 | 从工作室成长为自有算力中心 | 所有权、第一座集群、第一次永久加速 | 现有 8 服→机房→旗舰（v8 已实现）；完成后获得核心 1 |
| R2 | 多节点协同成稳定网络 | 拓扑协同、跨区域调度、已验证操作可批量 | 核心 2；批量购买已验证项目；早期流程压缩 |
| R3 | 全域治理成时代级基础设施 | 全局效率、系统韧性、最终时代工程 | 核心 3；更早自动化接管；最终高潮工程 + 地外计划揭示 |

### 2.4 时代工程（每轮唯一最昂贵的终局目标）

| 轮次 | 时代工程名 | 形态 | 完成后 |
|---|---|---|---|
| R1 | 区域算力协作网（沿用 v8 旗舰） | 旗舰工程 | 手动领取核心 1，执行第 1 次迭代，进入 R2 |
| R2 | 全球算力骨干环 | 全新旗舰（本轮唯一昂贵目标） | 手动领取核心 2，执行第 2 次迭代，进入 R3 |
| R3 | 行星算力统一场 | 全新旗舰（最终地球工程） | 手动领取核心 3，第 3 次迭代转化为地外算力计划揭示 |

- 价格定位：R2/R3 时代工程采用“本轮累计收入量的固定比例”定价，避免绝对值断档；CARD-00 以模拟校准，目标为完成时约占本轮累计收入的 60–75%。
- 获得动画：工程完成 → 全屏短促标题（2s 内）→ 粒子/光效（CSS）→ 奇点核心 n/3 跳变（n+1）→ 面板展示该枚核心的具体意义。
- 存档字段：见 §5（隔离实验 Schema，不落入正式 v3）。
- 重复领取保护：`singularity.coresClaimed` exactly-once；工程完成状态与领取状态分离（工程可完成但奖励未领，关闭后可从档案再次领取；已领取永不重发）。
- 玩家文案（示例，最终以 CARD-00 文案验收为准）：
  - 核心 1：“永久经营倍率 ×1.50；已验证项目可批量购买；早期流程已压缩。”
  - 核心 2：“永久经营倍率 ×2.00；全球算力骨干环为你的网络写入第二纪元。”
  - 核心 3：“永久经营倍率 ×2.50；地球算力网络达到物理极限——恒星级能源协议已检测到。”

## 3. 奇点核心（长期资产）

```yaml
singularity_core:
  display: "奇点核心 n/3"（n=已获得，顶部长期显示当前动态值）
  cap: 3 枚（地球主线限定）
  earn_rule:
    - 唯一时序：R1→核心1→迭代1→R2；R2→核心2→迭代2→R3；R3→核心3→迭代3转化为地外算力计划揭示→Stage4
    - 必须手动领取（不自动领取、不挂机领取）
    - 必须完成本轮时代工程（exactly-once）
    - 已领取永不重发
  meaning:
    - "1": 永久倍率 ×1.5；解锁已验证项目批量购买
    - "2": 永久倍率 ×2.0；压缩已学会的早期流程
    - "3": 永久倍率 ×2.5；触发地外算力计划揭示
  anti_farm: 永续模式禁止技术迭代与游戏内进度型清档/转生；设置中的“完整重置存档”保留并二次确认
```

## 4. 宇宙惊喜事件（第 3 枚核心触发，一次性）

触发条件：第 3 枚奇点核心手动领取后，第三次技术迭代转化为“地外算力计划”揭示，代替普通迭代页面触发。

- 全屏覆盖层：深空背景（CSS 渐变 + 粒子）、标题“地球算力网络达到物理极限 / 检测到恒星级能源协议 / 新的尺度已经解锁”。
- 唯一按钮：“启动地外算力计划”。
- 只触发一次（`singularity.spacePlanRevealed: true`）；可关闭（不自动进入新阶段）；关闭后可在“算力纪元/档案”重新打开该事件入口；玩家确认后才进入 Stage 4。
- 不再执行普通地球清档：第 3 次迭代不重置地球进度、不产生普通迭代结算页。
- 低成本全屏反馈：全屏颜色渐变、CSS 粒子、数字单位切换到宇宙量级（K/M/B→E/T 或专用“算力纪元单位”）、标题与身份切换；不依赖新图片/视频资产。

## 5. Stage 4：地月算力网

- 身份变化：地球算力大亨 → 地月算力运营商。
- 只保留三个核心动作：研发宇宙模型 / 购买轨道算力节点 / 推进地月超级工程。
- 内容包装（文字 + 图标 + CSS）：近地轨道节点、月球背面算力基地、地月激光链路、地外 AI 模型、最终工程“地月一体化算力网”。
- 禁止：运输、燃料、部件安装、轨道配置等复杂系统。
- 宇宙模型仅作阶段包装：沿用现有 6 模型图鉴承担永久收藏加成；不增加独立抽取、配置或复杂槽位。
- 进入时里程碑授予第一个轨道节点（不扣资金），确保尺度跃迁立即可见。
- 重新减速：Stage 4 独立经济曲线（新尺度），不被地球 ×2.5 瞬间跳过；目标在线等效 90–150 分钟（CARD-00 校准）。
- 数值门：**首次自费升级或第二个节点购买：进入阶段后 8–15 分钟**。
- 存档命名空间与 Review 入口隔离（见 §8）。

## 6. Stage 5：戴森算力纪元（最终终局）

- 身份变化：地月算力运营商 → 银河算力大亨。
- 复用三个动作：研发模型 / 购买恒星计算节点 / 推进巨构工程。
- 里程碑：太阳能采集阵列 → 戴森计算云 → 恒星级模型 → 最终唯一巨构“戴森算力球”。
- 进入时里程碑授予第一个恒星计算节点（不扣资金），确保尺度跃迁立即可见。
- 戴森算力球：全游戏最昂贵、最明确最终目标。
- 完成后：
  - 主线完成反馈（全屏结局 + 身份定格“银河算力大亨”）
  - 解锁“永续增长模式”
  - 永续模式仅禁止：**技术迭代** 与 **游戏内进度型清档/转生**
  - 设置中的“完整重置存档”必须保留并维持二次确认——不得把玩家永久锁死在单一存档
  - 玩家可继续购买、升级、观察数字永久增长
  - 不出现“未完待续”之类削弱结局的文案
- 目标在线等效 120–240 分钟（CARD-00 模拟调整）。

## 9. 排行榜（前置设计，默认 HOLD）

- 指标仅两个：主榜=历史最高算力；终局榜=银河纪元指数（占位名，公式不冻结）。
- 禁止：实时 PvP、公会、玩家攻击、强制社交、排行榜反向决定主线平衡。
- 正式接入前置（本阶段仅保留需求，不冻结公式）：云端权威校验（服务端重算/签名）、版本号校验（拒绝旧/异版本）、异常值过滤（量级钳制、增速上限、合法性校验）。
- 输入字段仅三组：历史最高算力、银河纪元指数（占位）、身份/纪元；版本化需求待 Stage 5 曲线与云端校验确定后再裁决。
- 排行榜仅限完成 Stage 5 的玩家可见；玩家可关闭排行榜展示。
- 未满足前置前保持 HOLD，不接入正式服务；不采集行为日志。
