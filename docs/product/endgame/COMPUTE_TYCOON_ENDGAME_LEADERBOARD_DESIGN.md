# 《算力大亨》终局排行榜前置设计（CARD-05｜默认 HOLD）

```yaml
card_id: CARD-05
status: HOLD（前置设计完成；不接入正式服务）
date: 2026-08-06
isolation: 本轮仅文档与数据合同；不落新存档字段、不采集行为日志、不改动正式引擎
dependencies: [CARD-03 通过]
cut: 整体 HOLD；云端校验未就绪前任何上线行为一律禁止
```

## 1. 目标与边界

- 提供未来竞争性的可见性，但不打扰主线；本轮无玩家可见变化。
- 禁止：实时 PvP、公会、玩家攻击、强制社交、排行榜反向决定主线平衡。
- 排行榜仅限完成 Stage 5（戴森算力球 + 永续）的玩家可见；玩家可关闭排行榜展示。
- 本地存档可修改导致排行失真：正式接入必须依赖云端权威校验，未解决前保持 HOLD。

## 2. 指标（仅两个）

| 榜 | 指标 | 定义 | 说明 |
|---|---|---|---|
| 主榜 | 历史最高算力 | 生涯中达到过的最高每秒算力/收入（确定性记录，单调） | 输入字段之一；正式口径待云端重算 |
| 终局榜 | 银河纪元指数 | 占位名；公式不冻结 | 等 Stage 5 曲线与云端校验确定后再裁决 |

- 银河纪元指数（Galactic Era Index, GEI）当前仅保留输入字段与版本化需求，不冻结公式。
- 禁止用排行榜反向决定主线平衡（如为榜单调整 Stage 5 数值）。

## 3. 输入字段（数据合同，仅设计）

```yaml
leaderboard_submission:
  schema_version: 1            # 版本化需求：拒绝旧/异版本
  player_id: string            # 匿名化玩家标识（不与正式存档绑定）
  metric_peak_compute: number  # 主榜：历史最高算力（单调不减）
  metric_galactic_era_index: number | null  # 终局榜：GEI 占位（null=未解锁终局）
  identity_era: string         # 身份/纪元（如 earth/earth_moon/dyson）
  stage5_completed: boolean    # 仅完成 Stage 5 的玩家可提交/可见
  submitted_at_ms: number
  client_version: string
```

- 仅三组输入：历史最高算力、银河纪元指数（占位）、身份/纪元 + 版本化需求。
- 本地存档不落新字段（不改变正式存档结构）。

## 4. 云端权威校验（正式接入前置）

| 需求 | 说明 |
|---|---|
| 服务端重算/签名 | 提交后由服务端基于可复算的存档快照重算指标，并返回签名；拒绝客户端自报值 |
| 版本号校验 | 拒绝旧/异版本客户端；正式 schema 升级时旧提交作废 |
| 异常值过滤 | 量级钳制、增速上限（如单次提交增幅超过合法上限即拦截）、合法性校验（时间戳/单调性） |

- 未满足上述前置前保持 HOLD，不接入正式服务；不采集行为日志。

## 5. 作弊边界与风险

- 本地存档可修改 → 历史最高算力/GEI 可被伪造。
- 对策：正式接入时只接受云端权威校验结果；本地值仅作为展示缓存，不作为榜单依据。
- 无云端时：任何排行榜都不上线（避免“本地修改即上榜”的公开作弊）。

## 6. 验收与自动化

- player_visible_acceptance：无 UI；交付文档与数据合同。
- automated_evidence：数据合同示例与异常值过滤规则单测（可选；本轮不实施正式服务）。
- stop_conditions：云端校验未就绪前任何上线行为。
