# 算力大亨 H5 1.0.0-rc.1

这是用于负责人最终手机验收的私密发布候选，不是公开发行版。

## 本版完成

- 主线完整贯通：工作室、服务器集群、三轮地球、地月算力网、戴森终局与永续经营。
- 修复旧档 R2/R3 核心事实迁移死锁、地外计划弹窗残留、Stage4 未取得四节点即可越级等阻断。
- 形成约 4–7 天普通回访节奏；首服和前 15 分钟体验保持不变。
- 真机测试包菜单保留 1/2/4/8/16/32/64/128/256× 体验倍率并关闭大帧状态漂移；普通正式入口不显示且拒绝倍率命令。
- 统一进度条、主题、模型蓝图文案、核心庆典与四栏页面：经营、荣誉馆、赞助、菜单；荣誉馆整合档案、15 项里程碑和名人堂。
- 新增原创分段 BGM《算力星潮》、重大动作音效和原创戴森终局主视觉；不再用连续振荡器生成背景音乐。
- 接入两类自愿赞助：离线结算从基础 6 小时按次扩容至 24 小时；经营收入 ×2 每次充能 2 小时，每日 3 次免费与 9 次广告额度；均有持久化 exactly-once 与待播放恢复保护。
- 存档升级至 schema v6，兼容旧 v1–v5；大数以高精度字符串保存。
- 云档 v2 冲突预检、双设备本地模拟和双排行榜大数安全评分已完成；Production 仍默认关闭，等待 TapTap 真容器验证。
- 银河终局新增自适应精度资金跳数与“银河网络实时结算”脉冲，终局不可升级但持续增长始终可见。
- 底部四栏、荣誉馆及主要经营卡统一使用 Lucide 单色矢量图标（ISC），移除这些玩家入口中的平台 Emoji 依赖。
- 增加持续运转的算力引擎、真实收入跃迁、可投资提示、关键节点爆发、离线回归反馈与阶段增长回顾；不改变经济、存档和广告规则。

## 当前关闭

- 云存档：等待 TapTap H5 真容器双设备上传/恢复/冲突验证。
- 银河名人堂双榜：等待真容器排序配置、可信 UID 与最低限度反篡改复核。
- 随机事件、签到、新货币、第四次迭代、戴森后无限解锁：不在首版范围。

## 最终人工验收重点

1. 手机阅读、点击、安全区和底栏是否舒服。
2. 普通回访下 4–7 天成长弧是否值得继续。
3. 两类赞助是否自然、24 小时上限和收入 ×2 是否清楚且不打断成就感。
4. 地月与戴森尺度跃迁、终局庆典是否有完成感。
5. 是否批准进入 TapTap 真容器测试与公开发布流程。
