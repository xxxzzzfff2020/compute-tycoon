## 本次游戏变化

- 同一页面从后台回到前台时，也会结算该隐藏区间的离线收益；重复可见事件不重复结算。保存失败会回滚本次内存结算，允许安全重试。
- 无资金报价时，使用结算前的时间锚点推进工程等有效离线进度；仍限制在原免费 2 小时内，不自动领奖或进入下一阶段。
- 离线回执增加本次已入账金额，修正工程名称和进度增量的文案占位符。
- 旗舰/时代工程展示基于实际进度和速度的预计剩余时间，并随进度更新。
- 起始机房明确说明由 8 台服务器自动汇聚。
- 同步正式基线的基础设施里程碑和工程门槛：第三旗舰工程需要光模块与存储 Lv8，时代工程需要两者 Lv10；存储奖励基准与启动门槛分离。时代工程的光模块速度加成遵守原有速度上限。

上述门槛来自本次正式 H5 基线，不是另行重做经济平衡。已在进行中的旧工程继续推进，不因新的启动门槛而重置。
