# GitHub 单机版：本地存档与平台功能说明

适用版本：`20260828-standalone-h5-v1`。此说明取代本文件此前的联网候选版描述；TapTap 原版不由本次发布修改。

## 本地存档

游戏仅把进度保存在当前浏览器本地存储中。菜单提供 JSON 导出、导入和完整重置；导入和重置需要明确确认。清理浏览器数据、使用隐私窗口或更换设备可能丢失进度，请提前导出备份。无效文件、未知未来版本或写盘失败不会覆盖有效进度。

## 账号与云备份

本版不读取平台 UID，不登录，不使用平台 SDK，不读取或上传云存档，也不等待账号初始化。不同浏览器/设备之间不会自动同步。历史存档中的本地 saveId 只用于本地存档兼容，不代表平台账号。

## 激励视频广告

广告功能已停用，广告页入口为不可点击状态。即使残留旧命令或旧广告回调，也不会播放或发奖；没有免费替代奖励。

- 离线收益保留正式 H5 基线的免费 2 小时额度与阶段效率；不提供广告扩容。
- 旧档已经解锁的离线收益保留，已领取部分不重复发放。
- 旧档已经获得的收入加速继续到期；未完成广告事件不会恢复或补奖。

本版不会请求广告展示或向广告平台提交统计。

## 排行榜

名人堂联网排名及提交/查询入口已移除。荣誉馆内仅保留本地档案、成就和个人历程。

## 网络边界

首次打开网页需要下载 GitHub Pages 提供的页面、图片和音乐等静态资源；游戏过程不依赖远端账号或游戏服务。本次不提供离线安装/PWA，也不代替静态托管服务自身的数据处理说明。
