## 单机版差异

- 不读取平台 UID，不登录，不探测或加载平台 SDK；启动仅使用当前浏览器本地存档。
- 移除名人堂排行榜及排名提交/查询入口。模型档案、成就奖励和个人经营历程仍保留在本地。
- 广告入口显示已停用，点击无效；命令层、会话层和旧奖励函数均拒绝广告，不播放、不发奖，也不替换成免费领取。
- 菜单提供本地 JSON 导出/导入。导入先明确确认；无效文件、未知未来版本或写盘失败不会覆盖现有进度。
- 正式包保持自然 1×，不包含验收检查点、调速面板或账号云档加载界面。
- 官网目录与 GitHub Pages 工作流保持原样。
