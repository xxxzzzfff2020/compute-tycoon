# 《算力大亨》H5 上架前最终真机测试流程

版本：`1.0.0-rc.1 · Final Device Test`

用途：负责人在 TapTap 小游戏真机测试环境对最终 ZIP 做上线前验收。

边界：只上传测试包，不提交审核、不发布。测试包菜单保留 1×–256× 体验倍率；普通正式包必须隐藏该工具。

## 0. 测试结论规则

最终只允许三种结论：

- `PASS_FOR_RELEASE_DECISION`：P0/P1 全通过，可以进入人工发布裁决。
- `ONE_REWORK_REQUIRED`：主线可完成，但存在一个可界定的上线前返修。
- `BLOCKED`：出现主线死锁、存档破坏、奖励重复、平台能力不可用或严重真机布局/性能问题。

遇到以下任一项立即停止，不继续浪费整轮时间：

- R1、R2、R3、Stage 4 或 Stage 5 任一阶段无法继续。
- 已满足条件但按钮不刷新、按钮点击无效、弹窗无法关闭。
- 重开后等级、核心、节点、资金或阶段倒退。
- Stage 4 未完成四个节点就能进入 Stage 5。
- 奇点核心、广告奖励、离线收益或终局奖励可重复领取。
- 页面横向被裁切、底栏不可点、刘海/平台测试提示遮住核心信息。
- 出现白屏、持续卡顿、音频失控、明显发热或崩溃。

发现问题时记录：阶段、倍率、设备、操作前状态、最后一次点击、截图/录屏；不要反复重试覆盖证据。

## 1. 准备（5 分钟）

- [ ] 确认上传的是本次 `FinalDeviceTest` ZIP，不是旧 Level A 包。
- [ ] 仅上传为 TapTap 测试包；确认未点击提交审核或发布。
- [ ] 记录 ZIP 文件名与 SHA-256。
- [ ] 设备 A：iPhone（优先此前使用的 iPhone 14 Pro Max）。
- [ ] 设备 B：一台中端 Android。
- [ ] 两台设备使用可区分的 TapTap 测试账号。
- [ ] 首次进入前清理该测试应用旧缓存，或在菜单执行“完整重置”。
- [ ] 关闭系统省电模式；记录网络类型与系统版本。

## 2. 最先执行：P0 全流程通路（约 30–60 分钟）

这一步先于广告、文案和舒适度细测。它必须证明本版本不会再次在第二轮或宇宙阶段卡死。

### 2.1 冷启动与首分钟（先保持 1×）

- [ ] 顶部身份、奇点核心、资金、收入、算力和倍率位于平台安全区下方，不被绿色测试提示或悬浮按钮遮挡。
- [ ] 底部只有四个主 Tab：经营、荣誉馆、赞助、菜单。
- [ ] 60 秒内理解：取得模型 → 处理业务 → 自动经营 → 买服务器。
- [ ] 取得第一款模型、完成首笔业务，按钮状态即时刷新。
- [ ] 自动经营后不出现“完成/领取”按钮，订单槽位不消失重建、不闪烁。
- [ ] 算力引擎、收入跳数和运行脉冲在不点击时仍持续工作，但不刺眼。

### 2.2 打开测试倍率

- [ ] 进入“菜单 → 真机体验工具”。
- [ ] 倍率选项完整：1/2/4/8/16/32/64/128/256×。
- [ ] 切到 256×；倍率切换只加速游戏模拟，不让 BGM、按钮动画或粒子变成频闪。
- [ ] 退出菜单后继续经营，倍率仍在当前会话生效。

### 2.3 Stage 1–3 与三轮地球纪元

- [ ] 租赁算力、第一台自有服务器、自动收入依次可达。
- [ ] 服务器购买后数量、算力和收入在同一画面立即跳升。
- [ ] 3/5/8 台服务器自动解锁三档集群架构，显示清楚且没有三选一旧入口。
- [ ] 模型统一使用“模型蓝图 / 蓝图等级 / 继续研发蓝图”，无“研发图鉴”等旧文案。
- [ ] 进入 Stage 3 后四类设施、机房和旗舰工程条件写清楚，满足条件时按钮即时可点。
- [ ] R1 时代工程“区域算力协作网”与普通旗舰“区域推理协作网”不重名。
- [ ] R1 完成后：领取核心 1 → 进入 R2；没有“后续未开放”死锁。
- [ ] R2“全球算力骨干环”完整完成，核心 2 可领取，进入 R3。
- [ ] R3“行星算力统一场”完整完成，核心 3 可领取。
- [ ] 三枚核心显示 3/3；第三次流程转化为“地外算力计划”，不执行普通地球清档。
- [ ] 地外计划弹窗“启动”与“关闭”都能立即关闭弹窗；稍后仍可重新打开。

### 2.4 Stage 4 地月算力网

- [ ] 进入时只授予第一个节点，后续节点需要真实购买。
- [ ] 四个节点依次完成；未到 4/4 前最终工程或 Stage 5 入口不可用。
- [ ] 第四节点购买后，算力/收入提升真实生效，不是只改文案。
- [ ] 地月最终工程完成后才可进入戴森阶段。

### 2.5 Stage 5 与永续终局

- [ ] 恒星节点按顺序建设，戴森算力球是唯一最终巨构。
- [ ] 戴森完成后终局庆典只出现一次；“继续经营”和“关闭”均能关闭。
- [ ] 荣誉馆档案、里程碑、传奇档案全部与实际完成进度一致。
- [ ] 终局后不再出现技术迭代、清档或新阶段按钮。
- [ ] 终局后资金和累计收入继续增长；“银河网络实时结算”持续可见，不是假动画。
- [ ] 终局后完整重置仍只存在于菜单，并需要二次确认。

P0 全流程结论：`PASS / FAIL`

## 3. 四个主 Tab 与最终文案（10–15 分钟）

### 经营

- [ ] 关键百分比、工程和成长进度均有清晰横条；无无意义频闪。
- [ ] 可投资提示只显示真实可执行动作、真实成本和真实预计提升。
- [ ] 节点突破和瓶颈释放有明显但克制的数字跃迁反馈。
- [ ] 阶段增长回顾使用真实历史数据，不遮挡主操作。

### 荣誉馆

- [ ] 三个子 Tab：档案、里程碑、名人堂。
- [ ] 模型、架构、科技、纪元、核心、成长历史和传奇档案可读且无 Emoji 占位图标。
- [ ] 达成时间使用北京时间；未完成项目不冒充已解锁。
- [ ] 没有“Production、Platform Review、Review、checkpoint、证据闭合、再裁决、存档ID、rev”等内部措辞。

### 赞助

- [ ] 只出现离线扩容与经营收入 ×2；没有插屏、Banner或强制广告。
- [ ] 不看广告也能继续完整主线。

### 菜单

- [ ] BGM、音效、音量、云备份、云端恢复、完整重置正常。
- [ ] 测试包底部显示体验倍率；不显示导入、导出、手动保存、返回首页。
- [ ] 菜单状态使用玩家语言，不出现研发流程说明。

最终文案结论：`PASS / ONE_COPY_REWORK`

## 4. 广告与离线收益（20–30 分钟，可分两次）

### 离线经营扩容

- [ ] 基础离线结算上限为 6 小时。
- [ ] 完整看一次广告，上限 +2 小时；显示今日次数 1/9。
- [ ] 连续充能最高 24 小时，超过后不可继续增加。
- [ ] 只有真实离线超过 6 小时并用到扩展区间时才消耗已充容量。
- [ ] 取消、失败、未看完均不加时、不扣次数。

### 经营收入 ×2

- [ ] 每日免费 3 次，每次 +2 小时。
- [ ] 免费次数用完后可看 9 次广告，每次 +2 小时。
- [ ] 总剩余时长不超过 24 小时。
- [ ] ×2 可与机房投产红利 ×4 同时生效，显示和真实收入都正确。
- [ ] 重复点击、后台切回、广告回调重复均只发一次奖励。

### 隔夜离线建议

- [ ] 睡前记下资金、收入/秒、阶段和离线上限。
- [ ] 完全退出应用，真实离线至少 7 小时。
- [ ] 次日回归报告显示：本次离线、有效结算、上限、超出时长、资金/工程变化。
- [ ] 未扩容时最多结算 6 小时；扩容后按当时上限结算，不无限膨胀。
- [ ] 离线不自动购买节点、不领取核心、不迭代、不跨阶段。

广告与离线结论：`PASS / FAIL / NEED_OVERNIGHT_EVIDENCE`

## 5. 云存档双设备（20–30 分钟）

- [ ] 设备 A 新档推进后“立即备份”成功，显示最近成功时间。
- [ ] 设备 B 从云端恢复，资金、阶段、核心、模型和服务器一致。
- [ ] 设备 B 继续推进并备份；设备 A 的旧进度不得静默覆盖新云档。
- [ ] 冲突时停止自动覆盖，并给出“先恢复 / 明确以本机覆盖”的选择。
- [ ] 空云档、损坏云档、未知高版本云档都不能覆盖有效本地档。
- [ ] 强制覆盖必须二次确认；取消后两端数据不变。
- [ ] 测试云槽不触碰此前正式本地档。

云存档结论：`PASS / FAIL`

## 6. 名人堂双榜（10–15 分钟）

- [ ] 未完成戴森的存档不能提交最短通关记录。
- [ ] 完成戴森后，最短通关榜按用时升序显示。
- [ ] 财富榜按真实大数顺序降序显示，不出现 Infinity、NaN或顺序反转。
- [ ] 两台设备/账号的 UID 与记录能区分。
- [ ] 同一档重复提交不会生成异常重复奖励或重复结算。
- [ ] 本地测试/Review伪造存档不能提交正式榜。

名人堂结论：`PASS / FAIL / SERVICE_CONFIG_BLOCKED`

## 7. 视觉、音频与性能（每台设备 15 分钟）

- [ ] iPhone 刘海/安全区：顶部不被测试提示或平台悬浮窗遮挡，底栏不压住内容。
- [ ] Android 竖屏：无横向滚动、文字裁切、底栏跳动或按钮过小。
- [ ] 地球 R1/R2/R3、地月、戴森主题切换正确，不因买服务器错误换色。
- [ ] Stage 1–5 分别播放五首独立 BGM，没有旧电流持续音或单曲分段复用；阶段过渡自然。
- [ ] BGM/音效开关、音量、锁屏/切后台/来电后恢复正确，不叠播。
- [ ] 重大节点有音效；订单完成不逐单轰炸。
- [ ] 1× 与 256× 各运行 10 分钟：无明显掉帧、触控迟滞、发热飙升或内存崩溃。
- [ ] 切后台 60 秒时视觉动画暂停；返回不补播粒子或音效。
- [ ] 系统“减少动态效果”开启时，核心信息仍可读、操作不丢失。

真机表现结论：`iOS PASS/FAIL · Android PASS/FAIL`
